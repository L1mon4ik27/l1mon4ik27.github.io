# L1mon | Devlog

Персональный сайт-визитка, выступающий в роли хаба для ссылок на социальные сети и разрабатываемые проекты.

## Функционал

- **Переключение цветовых тем:** Реализована поддержка светлой и темной темы. При первой загрузке скрипт анализирует системные настройки устройства с помощью `window.matchMedia`. При ручном переключении выбор пользователя сохраняется в `localStorage`.
- **Динамическая подмена графики:** В зависимости от активной темы логотип автоматически меняет цвет (используются разные файлы изображений).
- **Адаптивная верстка:** Интерфейс корректно отображается на мобильных устройствах и десктопах. Для выравнивания элементов используются CSS Grid и Flexbox.
- **Интерактивные элементы:** Ссылки стилизованы под кнопки с состояниями наведения (`:hover`) и плавными анимациями (`transition`).

## Структура проекта

```text

├── index.html          # Основная разметка страницы

│   └── style.css       # Стили, CSS-переменные, медиазапросы

```

## Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/L1mon4ik27/l1mon4ik27.github.io.git
   ```
2. Перейдите в директорию проекта и откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).

## Стек технологий

- **HTML5:** Семантическая разметка.
- **CSS3:** Кастомные свойства (CSS Variables), Flexbox, CSS Grid, анимации.
- **JavaScript (ES6+):** Манипуляции с DOM, работа с `localStorage`, определение системных предпочтений через `matchMedia`.
